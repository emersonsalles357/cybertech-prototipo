# CyberTech — Protótipo Startup One FIAP

Protótipo web navegável de alta fidelidade de uma plataforma SaaS B2B de governança e segurança para o uso responsável de inteligência artificial, voltada a pequenas e médias empresas.

## Como explorar

Abra `index.html` em um navegador moderno ou visite o site publicado pelo GitHub Pages. Na tela de acesso, clique em **Entrar na demonstração**. Não é necessário fornecer credenciais reais.

O protótipo inclui visão geral de governança, catálogo de IA, políticas de segurança, alertas fictícios, relatórios e auditoria, treinamento e planos de serviço. A navegação, filtros, diálogos, estados simulados e exportações de CSV funcionam no navegador. É possível restaurar os dados originais pelo menu **Reiniciar demonstração**.

## Escopo acadêmico

HTML semântico, CSS responsivo e JavaScript puro, sem dependências externas ou integração com serviços de IA. Todos os registros são fictícios; nenhum monitoramento, autenticação, armazenamento em servidor ou contratação real é realizado. O projeto utiliza apenas estados em memória durante a sessão de demonstração.
